1. 简介                                                        *Trans-intro*

Trans.nvim 是一个基于本地大模型的 Neovim 翻译插件。
它基于原作者 JuanZoran/Trans.nvim 的 v2 分支重构，默认使用 Qwen2.5-0.5B-Instruct，
通过 OpenAI 兼容的 HTTP 接口调用。百度、有道 API 作为可选备用后端。

模型文件不包含在仓库中，需要自行下载，详见 |Trans-model|。

==============================================================================
2. 命令                                                      *Trans-commands*

:Translate                 翻译光标下单词或选中文本。
:TranslateInput            输入一段文本进行翻译。
:TransPlay             朗读光标下单词或选中文本。

示例： >
    vim.keymap.set('n', 'mi', '<Cmd>TranslateInput<CR>')
    vim.keymap.set({'n', 'x'}, 'mm', '<Cmd>Translate<CR>')
    vim.keymap.set({'n', 'x'}, 'mk', '<Cmd>TransPlay<CR>')
<
==============================================================================
3. 配置                                                      *Trans-config*

配置文件默认位于插件目录下的 `Trans.json`，也可以通过 setup 修改目录： >
    require('Trans').setup {
        dir = require('Trans').plugin_dir,
        theme = 'default', -- default | tokyonight | dracula
    }
<
最小配置： >
    {
      "llm": {
        "uri": "http://127.0.0.1:8080/v1/chat/completions",
        "model": "qwen2.5-0.5b-instruct",
        "temperature": 0,
        "max_tokens": 256,
        "timeout": 60
      }
    }
<
百度 / 有道配置了 `app_id` 和 `app_passwd` 后才会启用： >
    {
      "baidu": {
        "app_id": "你的百度 app_id",
        "app_passwd": "你的百度密钥"
      },
      "youdao": {
        "app_id": "你的有道 app_id",
        "app_passwd": "你的有道密钥"
      }
    }
<
完整配置见 `lua/Trans/core/conf.lua`。

==============================================================================
4. 模型与服务                                                *Trans-model*

模型文件不包含在仓库中。下载脚本： >
    ./scripts/download-model.sh
<
默认下载到： >
    ~/models/qwen2.5-0.5b-instruct/qwen2.5-0.5b-instruct-q4_k_m.gguf
<
启动 llama.cpp 服务： >
    ./scripts/start-llm.sh
<
或手动启动： >
    llama-server \
      -m ~/models/qwen2.5-0.5b-instruct/qwen2.5-0.5b-instruct-q4_k_m.gguf \
      --host 127.0.0.1 --port 8080 -c 4096
<
使用 Ollama 时，接口改为
`http://127.0.0.1:11434/v1/chat/completions`，
模型名改为 `qwen2.5:0.5b-instruct`。

5. 性能与效果                                                *Trans-perf*

测试环境：Intel i7-9750H，6 线程 CPU 推理，Q4_K_M 量化。

    单词 / 短语                 约 0.1 秒
    整句                        约 0.3 ~ 0.5 秒
    冷启动后第一次翻译          约 0.7 ~ 1.3 秒
    内存占用                    约 630 MB

`temperature` 建议保持 0，输出更稳定，避免小模型出现半中半英。
0.5B 模型对常见词、技术术语和日常句子效果不错，长段落或专业文本仍可能出错。
内置的术语 / 习语示例见 `lua/Trans/backend/llm.lua` 中的 EXAMPLES。
